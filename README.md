# 📋 Quản Lý Nhân Sự

## 🌟 Giới thiệu
Dự án **Quản Lý Nhân Sự** là một ứng dụng Android được thiết kế để hỗ trợ quản lý thông tin nhân sự, phòng ban, và chức vụ trong tổ chức. Ứng dụng cung cấp các tính năng giúp quản lý hiệu quả, dễ dàng cập nhật và tra cứu dữ liệu.  

---

## 🛠️ Công nghệ sử dụng
- **Ngôn ngữ lập trình**: Java  
- **Cơ sở dữ liệu**: Firebase Realtime Database  
- **Công cụ phát triển**: Android Studio  
- **Giao diện người dùng**: XML, Material Design  

---

## ⚙️ Các tính năng chính
- **Quản lý nhân viên**:
  - Thêm, sửa, xóa thông tin nhân viên.  
  - Hiển thị danh sách nhân viên với các thông tin chi tiết.  
- **Quản lý phòng ban**:
  - Thêm mới phòng ban.  
  - Sửa đổi hoặc xóa phòng ban.  
- **Quản lý chức vụ**:
  - Cập nhật, chỉnh sửa thông tin chức vụ.  
- **Chức năng đăng nhập và đăng xuất**:
  - Đăng nhập với Firebase Authentication.  
  - Tích hợp chức năng đăng ký tài khoản mới.
